
Python is an interpretive language.

Compiler = Takes high level code and translates it to low level code (byte code).
Interpretor = Takes byte code and interprets it to machine code (on the fly)

C code will compiles into machine code, you do not need an interpretor.

Python execution chain = 

1. write high level code
2. press run
3. translates and read by interpretor
4. if syntax is correct, translated to byte code
5. byte code is translated to machine code and run
